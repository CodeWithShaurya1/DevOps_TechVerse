WHAT IS A CI/CD PIPELINE?

In modern software engineering, a CI/CD (Continuous Integration / Continuous Deployment) pipeline is the automated highway that takes code written by developers and safely puts it in front of millions of users.

Why Sequence Matters:
You cannot test code before fetching it, you cannot scan a container image before building it, and you must never deploy to production before passing quality gates!

Standard Pipeline Order:

  1. Source / Commit: Code changes are pushed and cryptographically signed.
  2. Quality & SAST: Automated linters, unit tests, and security scans run.
  3. Build & Artifact: Docker containers and Helm charts are compiled.
  4. Vulnerability Audit: Container CVEs and dependencies are verified.
  5. Staging & Production: Automated deployment with health probes and zero downtime.
